## 常见问题

**优惠码提示无效怎么办？**
先确认套餐不是 Pro 系列，再确认码是从当前活动页复制的。活动码按批次更换，从旧文章里抄来的字符串大概率已经失效。

**为什么结账金额没变？**
检查有没有点 Validate Code。填完不点，金额不会刷新。另外确认付款周期选的是不是季付以上，月付只有 8 折一层，看起来“没便宜多少”是正常的。

**年付本身已经 8.3 折了，还能再叠 8 折吗？**
能。周期折扣和活动码是两套体系，年付 8.3 折乘 8 折，约 6.6 折。这也是为什么建议先定周期再填码。

**续费会不会涨回原价？**
8 折是循环折扣，续费同享，年付的 17% 也是页面常驻价。唯一的不确定是活动期结束后码会不会调整，续费前看一眼账单就能确认。

**住宅 IP 和普通 VPS 差在哪？**
IP 属性不同。住宅系列给的是家庭宽带段地址，适合需要“看起来像本地用户”的场景；LAX 系列是常规机房 IP，开放 80/443，带 DDoS 防护，适合建站和通用业务。
